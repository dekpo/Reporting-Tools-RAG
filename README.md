# Reporting-Tools
A python app to convert transcripts, extract contents and anonymize them to ask ChatGPT for process...

## Setup
```bash
$ git clone <this-repo-url> reporting-tools
$ cd reporting-tools
$ py -m venv .venv
$ . ./venv/bin/activate (Linux)
$ . .venv\Scripts\activate (Windows)
$ py -m pip install -r requirements.txt
```
## Running

```bash
$ streamlit run app.py
```
